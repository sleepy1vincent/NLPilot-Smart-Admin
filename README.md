# NLPilot - 智能商品管理系统

> 自然语言驱动的商品管理。
> ⚠️ **实验性项目** —— 基于 7B 模型的 AI 工具调用，稳定性有限。

## ⚠️ 当前状态

- **版本**：v0.2（L2）
- **成熟度**：实验性 / Demo
- **已知局限**：见下文

## 支持的能力（范围）

### ✅ 稳定支持
- 查询商品（按名字）
- 新增商品
- 修改价格 / 库存
- 删除商品（带确认）
- 打折
- 记录销售 / 进货
- 查询销售 / 进货记录
- 销售统计

### ⚠️ 有限支持
- 模糊表达（"便宜的"、"卖得好的"）—— 依赖模型理解
- 多轮上下文（"给它打八折"）—— 有限
- 复杂语义 —— 不稳定

### ❌ 不支持
- 历史库存查询（"昨天库存多少"）
- 自主规划（"帮我做促销方案"）
- 多步推理（"对比一下"）

## 已知局限

本项目使用 **Qwen2.5-7B（Ollama 本地）** 做意图识别和工具调用。
由于 7B 模型的能力限制，**工具调用存在不稳定性**：

- AI 可能**没调工具**（直接回话）
- AI 可能**调错工具**（"查库存" → "记录销售"）
- AI 可能**参数错误**

**缓解措施**：
- 重试机制（3 次，不同 seed）
- prompt 调优
- 危险操作二次确认

**但无法 100% 消除** —— 这是当前 LLM Agent 的普遍现状。
